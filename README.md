# 非核心整合 (Non-Core Integration)

把**已吞并、但尚未核心化**的领土，在其**原主权国彻底灭亡**之后，逐个整合成本国核心。

- 游戏版本：**1.19.\***（1.19.3 实测可用）
- 不改地图 / 历史 / 国家 / 国策文件，**不覆盖任何原版路径**，可与其他 mod 共存

## 它做什么

游戏里会多出一个「非核心整合」决议分类。点决议 → 进入地图选点 → 点一个州，
走完 **45 天**进度条，该州获得你的核心，工厂 / 人力惩罚消失。

**只加核心，不转移所有权。** 如果你整合的是还没拥有的占领区，你拿到的是一份
永久法理宣称——日后和平会议把地正式划给你时它立刻就是核心，但在此之前地图上
那块地仍然是别人的颜色。这是「提前把地皮的手续办掉」，不是「隔空吞地」。

## 安装

1. 把 `noncore_integration/` 整个目录和同级的 `noncore_integration.mod` 放进
   `Documents/Paradox Interactive/Hearts of Iron IV/mod/`
2. 打开 HOI4 启动器 → **模组 (Mods)** → 左侧「本地模组」里勾选启用
3. 加进当前播放集，正常开始游戏

启动器里没立刻出现就重启一次启动器。

## 调参

`common/decisions/` 里两个文件已经用 `【调参①】`～`【调参⑤】` 标好位置：

| 编号 | 默认 | 作用 |
|------|------|------|
| ① | `always = yes` | 分类可见性，想只给一个国家用就换成 `original_tag = XXX` |
| ② | 可同时整合任意多个州 | 并发开关 |
| ③ | `cost = 50` | 每州政治点消耗 |
| ④ | `days_remove = 45` | 每州整合耗时（天），各州独立计时 |
| ⑤ | `factor = 0` | AI 是否使用此决议 |
